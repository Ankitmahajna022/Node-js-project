About This Project

A lightweight and efficient Todo App built with React & Express.

Why this project?

This Todo App was created to demonstrate a clean full-stack workflow using React on the frontend and Express.js on the backend. The main goal is to provide a scalable structure that can be easily extended.

Key Features

  • ✔ Add, edit, and delete todos
  • ✔ Filter todos by status
  • ✔ Responsive, modern UI
  • ✔ Clean folder structure

Tech Stack

Built with:

  • ⚛ React
  • 🚀 Express.js
  • 🔗 Axios
  • 🎨 Modern CSS styling

Future Goals

This project is actively improving! Expected future updates:

  • 🗂 MongoDB database support
  • 👤 User login system
  • 🎚 Priority levels for tasks
  • 🎉 Better UI animations
