# 🔐 React OTP Authentication System

A simple and secure authentication system built with **React** and **Node.js** that supports **Signup, Signin, OTP Verification**, and **Protected Dashboard access**.

---

## ✨ Features

- ✅ User Signup & Signin
- 🔑 OTP Verification via Email
- 🍪 Cookie-based Authentication
- 🔐 Protected Dashboard
- 🧭 Conditional Navbar (Signin & Signup only)
- ⚛️ React Router v6
- 📦 Axios for API calls

---

## 🛠 Tech Stack

### Frontend
- React
- React Router DOM
- Axios
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- JWT
- Nodemailer
- Cookie-parser
